# X1135 I-Mark 입력 시퀀스 변경 보고

- 작성일시: 2026-07-12 14:51:12 KST
- 대상 IO: X1135
- 목적: X1135를 I-Mark 입력 접점으로 등록하고, I-Mark 정지/검색 시퀀스와 UI 표시를 X1135 기준으로 변경
- 시퀀스 이미지: `20260712_145112_X1135_IMark_시퀀스.png`
- 상세 로그: `20260712_145112_X1135_IMark_작업상세로그.md`

## 변경 요약

1. `X1135`를 `IMarkCheckSensor`라는 전용 센서 파트로 추가했습니다.
2. 기존 I-Mark 검색/정지 판단이 `BlackMarkCheckSensor`를 보던 부분을 `IMarkCheckSensor`로 변경했습니다.
3. 초기화 시퀀스에서 `UseIMark`가 켜져 있으면 I-Mark 검색 분기를 타도록 기존 주석 처리된 분기를 복원했습니다.
4. 메인/수동 UI에 `X1135 I-Mark` 실제 입력 상태 램프를 추가했습니다.
5. `BlackMarkCheckSensor`는 기존 X1140 용지 확인 센서로 남겨 두었습니다.

## IO 및 파트 매핑

| 구분 | 변경 전 | 변경 후 |
|---|---|---|
| X1135 설명 | 비어 있음 | `SEALING UNIT) I-MARK INPUT CHECK` |
| RearLoadingUnit I-Mark 입력 | 없음 | `IMarkCheckSensor` 추가 |
| 실제 입력 | 기존 시퀀스가 `BlackMarkCheckSensor` 참조 | I-Mark 시퀀스가 `IMarkCheckSensor` 참조 |
| 입력 IO 번호 | 기존 I-Mark 판단은 X1140 센서 사용 가능성 | `X1135` 직접 사용 |

## 수정된 시퀀스 흐름

### 자동 로딩/피치 이동

1. `UseIMark` 확인
2. `UseIMark == false`
   - 기존 무마크 이동 경로(`UnUseIMark`)로 이동
3. `UseIMark == true`
   - `BandRollerServo.MoveTapeLoadingPos`로 가속 이동
   - `BandRollerServo.MoveTapeLoadingSlowPos`로 감속 검색
   - `IMarkCheckSensor.IsOn` 즉 X1135 ON 확인
   - X1135 ON이면 `BandRollerServo.Stop` 실행
   - `UseIMark` 완료 단계에서 카운트 증가 및 홈 마킹
   - 타임아웃이면 재검색, 재시도 초과 시 I-Mark 타임아웃 알람

### 초기화 시퀀스

1. `SealingBandCutting.Up`
2. `FourthPressServo.MoveHome`
3. `UseIMark`가 켜져 있으면 I-Mark 검색 경로 진입
4. `IMarkCheckSensor.IsOn`이 될 때까지 감속 검색
5. X1135 ON이면 롤러 서보 정지 후 다음 단계
6. `UseIMark`가 꺼져 있으면 기존 `UnUseIMark` 경로 유지

### 수동 I-Mark 검색

1. `SearchingImark` 시작
2. 작업자 확인창에서 동작 선택
3. `BandRollerServo.MoveTapeLoadingSlowPos` 실행
4. `IMarkCheckSensor.IsOn` 즉 X1135 ON 확인
5. X1135 ON이면 롤러 서보 정지 후 종료
6. X1135 OFF이면 `Searching` 단계 반복
