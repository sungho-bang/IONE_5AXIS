- 확인 대상: 설정 → 모터 → 피넛클 프레스 모터 → 이동

- 실제 장치 연결, 모터 구동, 현장 PC 원격 교체는 하지 않았습니다.

## 1. 원인

제공 화면은 오른쪽 PickPos가 45인데 왼쪽 위치 입력, 지령 위치, 현재 위치는 모두 0이었습니다.
제공 XML의 SecondPressServo는 AxisNo=9, PickPos.Position=0, HomePos.Position=0, TargetPosition.Position=0입니다.

모터 화면은 입력을 즉시 데이터에 반영하지 않는 Explicit 바인딩을 사용합니다. 기존 이동 버튼은 화면 입력을 반영하지 않고 SelectedPosition의 기존 내부값을 TargetPosition으로 복사했습니다.

또한 ConfigBaseControl의 모터 저장 목록 등록 이벤트가 성형 탭에만 연결되어 있었습니다. 피너클을 비롯한 나머지 탭은 저장을 눌러도 화면에서 입력한 새 값이 데이터에 반영되는 경로에서 빠져 있었습니다.

제공 로그에는 수동 이동 요청 및 목표값이 없어 당시의 장치 API 반환값은 확정할 수 없습니다. 이번 수정은 화면/XML/소스에서 확인되고 모의 시험으로 재현한 값 반영 누락을 해결합니다. 실제 리미트/서보 상태 검증을 대신하지 않습니다.

### 이동 버튼

1. 이동 가능한 위치가 선택되어 있는지 확인합니다. 읽기 전용 및 토크 항목은 위치 이동 대상으로 허용하지 않습니다.
2. 선택한 위치의 오른쪽 표/왼쪽 입력값을 변경 전에 모두 수집합니다.
3. 숫자 형식, 유한한 값, 설정된 위치 한계, 양수 운행 속도/속도 비율/가감속 시간/축 배율을 확인합니다.
4. 변경하지 않은 왼쪽의 0이 오른쪽에 입력한 45를 덮어쓰지 않도록 변경값만 반영합니다. 좌우에 각각 다른 새 값을 입력한 경우에는 차단합니다.
5. 선택한 위치만 반영하고 TargetPosition을 설정합니다. 다른 위치의 미저장 편집은 이동 명령에 섞지 않습니다.
6. 기존 인터록을 확인하고 기존 MoveToPos.Execute 경로로 요청합니다. 자동 Servo ON이나 인터록 무시는 추가하지 않았습니다.

이동 버튼은 디스크에 자동 저장하지 않습니다. 재실행 후에도 유지하려면 기존 저장 버튼을 사용해야 합니다.

### 저장 버튼

- 저장만으로 모터를 움직이지 않습니다.

## 4. 진단 로그

새 수동 이동 기록은 실제 실행 파일 폴더 기준 아래 위치에 저장됩니다.

`Log\SystemLog\YYYY\MM\YYYY-MM-DD.log`

현재 Debug 기준 예:

`D:\Works_Updates\대주이엔지\Git_IONE_5AXIS\FAFramework\bin\Debug\Log\SystemLog\2026\09\2026-09-10.log`

검색어: `[MotorManual]`

기록 필드: Result, Part, Axis, Selected, Target, StartSpeed, DriveSpeed, SpeedRate, Scale, Actual, Command, ServoOn, Alarm, LMTMinus, LMTPlus, Detail.

| Result | 의미 |
|---|---|
| REQUEST | 입력 검증 및 목표 반영 후 이동 요청 직전 |
| REJECTED | 입력 오류, 읽기 전용, 위치 선택 오류 등 |
| INTERLOCK | 기존 인터록 확인에서 차단됨 |
| RETURNED | 이동 함수가 반환됨. 장치 수락 또는 이동 완료 보증이 아님 |
| EXCEPTION | 이동 요청 중 예외 발생 |

기존 MovePos API의 비정상 반환 코드는 작업 폴더 기준 LOG\PART_LOG에 기록하는 구조를 유지합니다. REQUEST/RETURNED만으로 물리 이동 성공을 판단하지 않습니다. 확인 시 같은 시각의 SystemLog, PART_LOG(존재 시), 전체 모터 화면을 함께 사용합니다.

## 5. 검증 결과

- Debug x86 빌드: 오류 0개, 기존 경고 18개.
- 모터 UI/저장 시험 28개 통과.
- 기존 I-Mark 회귀 시험 102개 통과.
- 재현: 원본 XML PickPos=0 → 오른쪽에 45 입력 → 이동 전 내부값/왼쪽 0 유지 → 수정된 이동 처리 후 목표/좌우 입력 45 → 모의 이동 후 지령/현재 45.
- 실제 SaveParameters/LoadParameters로 저장 및 재로드 후 PickPos=45 확인.
- 성형 PickPos=15, 축 8 유지 및 피너클 축 9/배율/속도 비율 보존 확인.
- 빈 값, 비숫자, NaN/무한대, 위치 한계 초과, 속도 0, 음수 시작 속도, 좌우 충돌 입력 차단 확인.
- 저장 시 다른 탭에 오류가 있으면 정상 탭도 먼저 변경하지 않는지 확인.
- 실제 WPF 이동 버튼은 SimulationMode에서만 실행했습니다. 물리 모터/컨트롤러에는 연결하지 않았습니다.

시험 이미지에는 가독성을 위해 이름 열의 폭만 시험 코드에서 조정했습니다. 운영 UI의 열 폭/레이아웃은 변경하지 않았습니다.
