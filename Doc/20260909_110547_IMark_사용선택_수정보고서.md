# 메인 I-Mark 사용 / 미사용 선택 추가

작성일: 2026-09-09
대상: D:\Works_Updates\대주이엔지\Git_IONE_5AXIS

## UI 위치

메인 화면의 '실링 전원 ON / OFF' 오른쪽, 기존 작은 '아이 마크' 표시 자리에 다음 항목을 추가했습니다.

- 제목: I-Mark X1135
- 선택: 사용 / 미사용
- 두 항목은 라디오 버튼이며 하나만 선택됩니다.
- 현재 시퀀스에 적용된 RearModule.UseIMark 값을 표시합니다.
- 최초 화면 표시나 바인딩 갱신만으로 설정이 바뀌지 않도록, 변경 처리는 실제 Click에서만 수행합니다.

## 선택 시 반영

메인의 RECIPE에서 대상 JOB을 선택한 상태에서 변경합니다.

| 반영 대상 | 내용 |
|---|---|
| RearModule.UseIMark | 현재 운전 시퀀스가 참조하는 사용 여부를 즉시 변경 |
| MainLoopModule.MoveJobInfo.UseIMark | 현재 운전 JOB 정보에 같은 값 반영 |
| 선택 JOB의 MoveJobInfo.UseIMark | 설정 화면에서 보는 JOB에도 같은 값 반영 |
| 다른 JOB / Offset / 모터 위치 및 속도 | 변경하지 않음 |

사용 선택: 다음 I-Mark 피딩에서 기존 X1135 감지 및 보정 흐름을 사용합니다.
미사용 선택: 자동/1사이클/일반 수동 피딩에서 기존 위치 피딩 분기를 사용하며 I-Mark 감지 보정은 생략합니다.
모드 선택만으로 모터나 시퀀스를 시작하지 않습니다.
전용 'I-Mark 찾기'와 별도의 수동 연속 명령 정책은 앞선 시퀀스 변경 그대로 유지했습니다.
모터번호 AxisNo=4, 입력 X1135, Offset 계산 및 4축형 I-Mark 시퀀스는 이번 작업에서 바꾸지 않았습니다.

## 변경 제한

다음 경우 사용/미사용 선택을 비활성화합니다. 클릭 처리 시에도 같은 조건을 다시 확인합니다.

- 장비 또는 모터/운전 JOB 설정이 아직 로딩되지 않음.
- RECIPE의 JOB이 없거나 실제 JOB 목록 및 선택 JOB 이름과 일치하지 않음.
- 설비가 정지 상태가 아님.
- 자동운전, 초기화, JOB 로딩, 전체 1사이클, Rear 피딩/찾기/컷팅, 롤러 위치 이동 등 관련 시퀀스가 진행 중임.
- 관련 시퀀스가 일시정지(Suspended) 또는 정지 진행(Suspending) 중임.
- 롤러 RunFlag가 켜져 있음.

관련 시퀀스가 종료/중단된 후 정상 정지 상태에서 다시 변경할 수 있습니다.
단순 일시정지는 재개할 동작이 남아 있으므로 설정 변경 가능 상태와 구분했습니다.
변경 불가 이유와 저장 안내는 선택 영역 툴팁에서 확인할 수 있습니다.

## 저장 방법

메인에서 선택한 값은 즉시 메모리에 반영됩니다.
재실행 후에도 유지하려면 '설정 → 하단 저장'으로 저장해야 합니다.
메인 클릭만으로 모든 미저장 JOB 편집 내용을 자동 저장하지 않도록 기존 저장 절차를 유지했습니다.

기본 Debug 실행의 JOB 저장 파일:

```text
D:\Works_Updates\대주이엔지\Git_IONE_5AXIS\FAFramework\bin\Debug\config\VT3500\jobfile.xml
```

선택한 JOB의 MoveJobInfo/UseIMark 값이 저장됩니다.
설정 화면에서 다른 JOB을 선택하고 있는 경우 메인에서 선택한 JOB과 구분해야 합니다.
이번 작업 중 실제 장비의 JOB XML이나 사용 여부를 직접 변경하지 않았습니다.

## 기존 숨은 연결 수정

기존 메인 하단 '전체 1회운전', '포장 1회운전' 제목이 ToggleButton으로 되어 있고,
Checked/Unchecked 이벤트에서 RearModule.UseIMark를 true/false로 바꾸고 있었습니다.

이 두 제목은 일반 TextBlock으로 변경하여 I-Mark 설정을 바꾸지 않게 했습니다.
그 아래 실제 '시작' 버튼과 1사이클 명령 연결은 유지했습니다.
사용 여부 변경은 새 I-Mark 선택 항목에서 명시적으로 수행합니다.

RECIPE 선택 변경 처리도 함께 정리했습니다.
선택 해제 시 빈 AddedItems를 접근하던 예외 위험을 제거하고,
전역 장비 인스턴스 대신 현재 화면의 EquipmentInstance에 연결했습니다.

## 상세 로그

기존 전용 IMarkLog에 다음 이벤트를 추가했습니다.

| 이벤트 | 내용 |
|---|---|
| MAIN_USAGE_CHANGED | Source=MainUI, JOB, 이전값, 선택값, 저장 필요 상태 |
| MAIN_USAGE_CHANGE_REJECTED | 변경 차단 사유. 실제 클릭 처리가 차단된 경우 |
| USE_IMARK_CHANGED | 기존 RearModule 설정 변경 로그도 유지 |

변경 이벤트의 Persistence=PendingConfigSave는 메모리 반영 상태이며 파일 저장 완료를 의미하지 않습니다.

실제 운전 중 로그 위치:

```text
D:\Works_Updates\대주이엔지\Git_IONE_5AXIS\FAFramework\bin\Debug\Log\VT3500\IMarkLog\YYYY\MM\YYYY-MM-DD.log
```
