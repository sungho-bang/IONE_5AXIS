# FRONT I-Mark X1135 로그 분석 안내

## 현재 제어 대상

- 흐름 식별자: Flow=FrontGripperX1135V1
- 모듈/축: FrontModule / TapeLoadingServo / 현재 설정 AxisNo=1
- 입력: FrontIMarkCheckSensor / X1135
- REAR BandRollerServo는 이전 X1140 BlackMark 기능으로 복원되어 별도의 기존 TraceLog를 사용합니다.

## 실제 로그 위치

실행 파일 폴더를 기준으로 Log/설비명/IMarkLog/YYYY/MM/YYYY-MM-DD.log 에 기록합니다.

현재 Debug, VT3500 기준:

D:\Works_Updates\대주이엔지\Git_IONE_5AXIS\FAFramework\bin\Debug\Log\VT3500\IMarkLog\2026\09\2026-09-09.log

프로그램을 다른 폴더에서 실행하면 해당 실행 폴더의 Log를 확인해야 합니다. 기본 보관 기간은 기존 7일이며, 이번 축 변경에서 로그 삭제 설정을 바꾸지 않았습니다.

## 기록 내용

| 필드/이벤트 | 분석 목적 |
|---|---|
| Flow, CycleId | 이번 FRONT 흐름과 피치 실행 구분 |
| RunId, Seq, Caller, ElapsedMs | 시퀀스 실행별 식별, 부모/자식 호출과 진행 시간 |
| Step, StepName, Action, SeqState | 어느 단계에서 지연/정지했는지 |
| InputName, RawInput, CorrectedInput, IOInverse, InputInverse, Sensor | 원시 입력, 보정 입력, 논리 상태 비교 |
| Axis, ActualPos, CommandPos, RunFlag, MotionDone, ServoOn, ServoAlarm | 대상 축과 위치/상태 |
| FastPosition/Speed, SlowPosition/Speed, Accel/Decel, TimeoutMs | 실제 적용된 탐색 설정 |
| Offset, OffsetTarget, DetectedPos, AppliedOffset | 감지 위치와 보정 목표 비교 |
| LoadGrip, HoldGrip, LoadGripIO, HoldGripIO | 그리퍼 논리 상태 및 실제 매핑된 입력/출력 값 |
| LoadGripState, HoldGripState, LoadReleaseState, HoldReleaseState, HomeState | 실린더 인계와 복귀 시퀀스 상태 |

부모 시퀀스의 시작 시점에는 이전 피치 CycleId가 남아 있을 수 있습니다. 실행 구분은 RunId를 기본으로 사용하고 Seq/Caller/시간 및 자식이 시작된 이후의 CycleId를 함께 확인합니다.

## 정상 흐름에서 찾을 이벤트

START → POSITIONING_BEGIN → FAST_MOVE_WAIT_COMPLETE 단계 → SLOW_SEARCH_COMMAND → DETECTED_STOP_REQUESTED → STOP_CONFIRMED → OFFSET_MOVE_PREPARED → OFFSET_MOVE_COMPLETED → POSITIONING_COMPLETED → FRONT_FEED_DISTANCE → TERMINATED

입력이 고속 이동 후 이미 ON이면 SLOW_SEARCH_COMMAND 없이 감지 처리로 갈 수 있습니다.

Offset 0이면 OFFSET_SKIPPED가 기록됩니다. 같은 ON 재처리 방지는 SAME_ON_SKIPPED, 미사용 운전은 BYPASS로 구분합니다.

부모 시퀀스 로그에서 고정 그리퍼 Grip 후 이송 그리퍼 Release, 다음 복귀 단계의 HomeState와 재파지 상태를 확인합니다. MOTOR/그리퍼/IO 상태 변화는 MOTION_CHANGED에도 기록됩니다.

## 오류와 재개

- POSITIONING_FAULT_STOP_REQUESTED / POSITIONING_ALARM: Reason과 마지막 위치, 그리퍼 상태를 확인합니다.
- SearchTimeout: 저속 지령 시점부터 TimeoutMs 이내에 새 ON을 받지 못했습니다.
- InvalidOrMissingInput: 센서 객체 누락 또는 정상 On/Off로 해석할 수 없는 입력입니다.
- GripperInterlock: 이송 그리퍼 Grip / 고정 그리퍼 Release 조건이 충족되지 않았습니다.
- OffsetTargetOutsidePositionLimits: 보정 목표가 설정된 위치 한계를 넘었습니다.
- StopOverrunBeyondOffsetTarget: 정지 후 이미 보정 목표를 허용오차보다 지나쳤습니다. 역방향 보정을 강행하지 않습니다.
- InitializeRequiredAfterInterruptedPositioning: 이전 감지/보정 동작이 오류 또는 강제 중단되어 초기화가 필요합니다.
- SUSPEND_REQUESTED, SUSPENDED, RESUMED, SLOW_SEARCH_RESUMED: 정상 일시정지/재개 구분.
- ABORTED, POSITIONING_ABORT_STOP_REQUESTED: 정상 완료가 아닌 강제 중단입니다.
- 장시간 대기는 5초 주기 HEARTBEAT, 같은 반복 이벤트는 횟수 요약을 사용합니다.

## 문의 시 함께 제공할 자료

1. 이상 발생 시각과 해당 날짜 IMarkLog 원본 전체.

3. 적용 JOB 이름, FRONT 사용 여부, 원단 피치, 저속 탐색 거리, Offset.
4. 그리퍼 모터 TapeLoadingPos/TapeLoadingSlowPos 속도, 가감속, 위치 한계.
5. 현상: 멈추지 않음, 너무 늦게 정지, 보정 후 실린더 미동작, 복귀 지연 등.
6. 수동 원단 1피치인지 자동/전체 1회 운전인지, 정지/재개/초기화 조작 여부.
