## 2. 수정 항목

### 생산 코드

`FAFramework\VT3500\Modules\FAFrontLoadingModule.cs`의 `UnUseTomson1`만 변경했다.

- 중복 `TapeLoadingMoveWithIMark` 호출 제거.
- 중복 고정 그리퍼 Grip / 이송 그리퍼 Release 호출 제거.
- 두 번째 사용량 합산 단계 `InitEnd1`로의 이동 제거.
- 최초 피딩 완료 상태를 로그에 기록한 후 정상 종료.
- 정상 종료 이벤트의 기존 `RModule.ReSet = true` 처리 유지.
- I-Mark 미사용에서도 같은 물리적 중복 호출 및 사용량 중복 합산 방지.

```text
수정 전, 최초 피딩 / 톰슨 미사용:
피딩 -> 고정 그리퍼 Grip -> 이송 그리퍼 Release -> 사용량 합산
     -> 같은 피딩 재호출 -> GripperInterlock

수정 후, 최초 피딩 / 톰슨 미사용:
피딩 -> 고정 그리퍼 Grip -> 이송 그리퍼 Release -> 사용량 합산
     -> FIRST_FEED_ALREADY_COMPLETED 기록 -> 정상 종료

다음 반복:
기존 프레스 처리 / 그리퍼 원점 복귀 -> 이송 그리퍼 Grip -> 고정 그리퍼 Release
     -> 다음 피딩 -> 그리퍼 인계 -> 사용량 합산
```

톰슨 사용 시 프레스 및 원점 복귀를 거쳐 실행되는 후속 피딩, 반복 운전의 `UnUseTomson` 및 재료 유무 / 바이패스 분기는 제거하지 않았다. 필요한 FRONT 피딩 호출 지점은 10개에서 9개로 줄었다.

### 유지한 사항

- `TapeLoadingServo` 축 1, 입력 X1135.
- 이송 그리퍼 X0230/X0231, Y0324/Y0325.
- 고정 그리퍼 X0232/X0233, Y0326/Y0327.
- REAR `BandRollerServo` 축 4 및 기존 X1140 로직.
- 이동 전 그리퍼 인터록과 중단 후 초기화 요구.
- 기존 ON 유지 시 `SAME_ON_SKIPPED` 판정, 새 OFF/ON 감지 및 저속/오프셋 로직.

이번 수정은 저속 탐색의 무조건 실행이나 센서 입력 무시가 아니다. 기존 ON 유지 시 저속 생략 조건은 그대로이므로, 중복 호출 해결과 저속 감지 조건 변경을 구분해야 한다.
