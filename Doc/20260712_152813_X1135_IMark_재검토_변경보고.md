# X1135 I-Mark 시퀀스 재검토 및 변경 보고

- 작성일시: 2026-07-12 15:28:13
- 대상 설비: VT3500 / 5AXIS
- 요청 IO: X1135
- 목적: X1135를 I-Mark 입력 접점으로 사용하도록 시퀀스, 설정 XML, UI, 문서 산출물을 재검토하고 누락 사항을 보완

## 결론

X1135 I-Mark 입력은 RearLoadingUnit / RearModule 쪽에 연결되어 있는 것이 현재 소스 구조상 맞습니다.

근거는 다음과 같습니다.

- `FourthPressModule.RModule = RearModule`
- `RearModule.FourthPressUnit = FourthPressUnit`
- 실링/4축 관련 롤러 이동, 컷팅, I-Mark 탐색 시퀀스가 `FARearLoadingModule` 안에 있음
- 작업 조건 `MoveJobInfo.UseIMark`가 작업 로드 시 `RearModule.UseIMark`로 전달됨

## 이번 재검토 후 추가 수정

기존 반영 내용은 유지했고, 재검토 중 발견한 내부 명칭/안전성 부분을 추가 보완했습니다.

1. `FARearLoadingModule`에 I-Mark 센서 접근 헬퍼 추가
   - `IsIMarkInputOn()`
   - `IsIMarkInputOff()`
   - `GetIMarkInputStatus()`
   - 목적: `IMarkCheckSensor`가 누락되었을 때 NullReferenceException으로 즉시 중단되지 않도록 방어

2. 수동 I-Mark 탐색 시퀀스 내부 step 이름 정리
   - 기존 내부 이름: `BlackMarkCheck`, `BlackMarkCheckRetry`
   - 변경 이름: `IMarkCheck`, `IMarkCheckRetry`
   - 목적: 실제 사용 IO가 X1135 I-Mark이므로 로그/시퀀스 명칭 혼선 제거

3. 로그 문구 정리
   - 기존: `Retry Sensing Black Mark`
   - 변경: `Retry Sensing I-Mark`

4. 중복 using 제거
   - `FARearLoadingModule.cs`의 중복 `using FAFramework.VT3500.ExtendedParts;` 제거
   - 빌드 경고 1건 감소

## 기존 반영 상태 재확인

### 센서/Part 연결

| 항목 | 파일 | 확인 내용 |
|---|---|---|
| Rear SubUnit 속성 | `FAFramework/VT3500/SubUnits/FARearLoadingUnit.cs` | `IMarkCheckSensor` 추가됨 |
| Rear Module 속성 | `FAFramework/VT3500/Modules/FARearLoadingModule.cs` | `IMarkCheckSensor` 추가됨 |
| Rear Part XML | `FAFramework/bin/Debug/config/VT3500/RearLoadingUnit/PartList.xml` | `IMarkCheckSensor`가 `X1135`에 연결됨 |
| DeviceList | `FAFramework/bin/Debug/config/DeviceList.xml` | `X1135 = SEALING UNIT) I-MARK INPUT CHECK` |

참고: `CommonUnit/PartList.xml`에도 `X1135`가 있으나 이는 `IOList` 공용 IO 목록에 포함된 것이며, 별도 센서 Part 중복 등록은 아닙니다.

### Job 사용 유무

| 항목 | 파일 | 확인 내용 |
|---|---|---|
| Job 옵션 속성 | `FAFramework/VT3500/JobInfo/MoveJobInfo.cs` | `UseIMark` 저장/복사/로드 처리 존재 |
| Job 로드 전달 | `FAFramework/VT3500/Modules/FAMainLoopModule.cs` | `MoveJobInfo.UseIMark`가 `RearModule.UseIMark`로 전달됨 |
| Job 설정 UI | `FAFramework/VT3500/GUI/PositionControl.xaml` | `I-Mark X1135` 토글이 `JobInstance.UseIMark`에 바인딩됨 |
| 현재 상태 표시 | `FAFramework/VT3500/GUI/MainStatusControl.xaml` | `아이 마크`, `I-Mark X1135` 상태 표시 존재 |

### 시퀀스 반영

| 시퀀스 | 반영 내용 |
|---|---|
| Initialize | `UseIMark=true`이면 X1135 I-Mark 입력을 찾고, `false`이면 미사용 경로로 이동 |
| MovingRoller | `UseIMark=true`이면 고속 이동 후 감속 검색, X1135 ON 시 정지/홈마킹 |
| ManualWorkLoading | 수동 로딩에서도 `UseIMark` 기준으로 `IMarkCheck` 경로 사용 |
| WorkManualLoading | 수동 연속 로딩 루프에서 X1135 ON/OFF 상태 확인 |
| SearchingImark | 별도 I-Mark 찾기 수동 시퀀스에서 X1135 ON 확인 |

## UI 위치

### 작업 조건 사용 유무

- 화면: `설정` -> `JOB 설정`
- 위치: 현재 보이는 JOB 설정 화면에서 아래로 스크롤 -> `옵션` 영역
- 항목: `I-Mark X1135`
- 동작: `사용` 토글
